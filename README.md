## Verification Standards & Methodology

- **Evidence Tier E1 (Cryptographic & On-Chain Ground Truth):** Direct on-chain program IDs, deployed bytecode, verified transaction hashes, and live hardware probe logs.
- **Evidence Tier E2 (Code & Commit Verified):** Verifiable in public or local source code, commit SHAs, line diffs, and passing test suites.
- **Evidence Tier E3 (Documentary Claim):** Stated in design documentation or specifications but not yet independently benchmarked.
- **Evidence Tier E4 (Disallowed / Caveated):** Claims strictly excluded from professional representations without explicit qualification.
